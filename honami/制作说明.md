# 一之濑帆波 (Honami) 桌宠主题 制作说明

同人图，个人本地使用，不分发。当前版本 0.4.0，使用大头版原图 v5。

## 总原则
- **任何脸部都不做交叉淡化**。姿势之间一律用画好的中间帧逐帧硬切（每帧 90-130ms，像手绘动画）；表情变化（眨眼、翻页、抬头笑换头）也是硬切。
- 每帧按"地面基线（鞋底）+ 统一缩放（头部大小一致）"对齐，头部的左右位置沿一条平滑路径移动（脚本里 `path()`）。

## 流程
1. 切格：A/B 图（1536x1024，3x2）、S/T（1024x1024，2x2）、T2/Z/W（1536x1024，3x2）按 512 切格。
2. 去绿幕：量出背景绿，按 G-max(R,B) 算 alpha，再反解前景色（白描边保留、无绿溢色）；删掉小碎块和贴格边的碎块。
3. 眨眼：A、B 做差得到眼睛掩码，只把 B 的眼睛贴到 A 上（带羽化，不整格切换）。
4. 统一缩放（待机图高约 400px）、脚底为锚点，程序变换（呼吸、转动、弹跳、挤压）。
5. 输出动画 WebP（每帧可变时长，循环）和 theme.json；单文件超 4MB 时脚本自动降画质。

## 状态与动作（文件大小：见 assets/）
| 状态 | 内容 | 时长 |
|---|---|---|
| idle | 7 秒循环：呼吸 3% + 轻摆 ±1.5°，眨眼 单、单、双 | 7000ms |
| thinking | 待机 -> W1 -> W2 -> 思考循环（歪头 ±3°、呼吸、眨眼，约 11 秒）-> W2 -> W1 -> 待机；首尾都是待机帧，循环接缝无跳变 | 12000ms |
| working | 待机 -> W3 -> W4 -> W5 -> 工作保持段（呼吸 2%、眨眼，中间一次 W6 抬头微笑约 1.7 秒，共约 45 秒）-> 倒放回待机 | 46700ms |
| notification（error 同） | 弹 3 下 + 眨眼；minDisplay/autoReturn = 全长 | 5040ms |
| attention | 欢呼弹 3 下；minDisplay/autoReturn = 全长 | 3080ms |
| sleeping | 慢呼吸 4%（循环） | 5040ms |
| yawning（睡眠序列，一次性） | 待机 -> Z1 打哈欠（停 0.8 秒）-> Z2 -> 屈膝 -> Z3 -> Z4 -> 睡觉首帧 | 1590ms |
| waking（一次性） | 睡觉首帧 -> Z5 睁眼（停 0.7 秒）-> Z6 揉眼（停 0.9 秒）-> 屈膝两小步 -> Z2 站定 -> 待机首帧 | 2540ms |

睡眠用 clawd 完整序列（`sleepSequence.mode = "full"`）：鼠标 5 分钟不动（mouseSleepTimeout=300000）-> yawning（yawnDuration=1590）-> dozing（复用 sleeping.webp）-> 6 分钟后（deepSleepTimeout=360000）collapsing（复用 sleeping.webp，collapseDuration=100）-> sleeping；动鼠标 -> waking（wakeDuration=2540）-> 回到正常状态。yawning 末帧 = sleeping 首帧，waking 首帧 = sleeping 首帧，waking 末帧 = idle 首帧（像素差 0）。

闲置小动作（鼠标 20 秒不动后随机播一个；首尾都是 idle 首帧，像素差 0.00；全部硬切、脚不动）：
- idle_tilt 歪头（4300ms）：待机 -> C1 -> C2 点脸颊 -> C3 眯眼笑 -> C4 wink 吐舌 -> C3 -> C6 双手贴脸 -> C5 -> C1 -> 待机；没有任何上下位移。（没有叠加头部旋转：整图绕脖子转会带着身体转，只转头需要换头贴图，有接缝风险，所以没做。）
- idle_look 张望（3900ms）：待机 -> K4 手搭凉棚 -> K5 看左（1.4 秒）-> K4 -> K6 看右（1.4 秒）-> K4 -> 待机。
- idle_stretch 伸懒腰（3100ms）：待机 -> K1 -> K2 双臂举高闭眼（1.3 秒，含两次 1.4% 的小幅向上拉伸做"用力"）-> K3 略侧弯（0.9 秒）-> K2 -> K1 -> 待机。
- idle_pat 摸头（7300ms，2026-10-30 替换原来的“点头”；原画 `raw/sheet-H-v6.png`（在 v5 上只重画了手：更瘦长、骨节清楚；人物像素不变），细长男生手，整张缩放 0.93 对齐待机大小；`sheet-P-v5.png` 是被否掉的第一版：手太胖、动得太多）：待机 -> H1 手落在头顶、抬眼（0.7 秒）-> H2 往左歪眯眼笑（0.9 秒）-> H4 回正 -> H3 往右歪 ω 嘴（0.9 秒）-> H4 -> H2 -> H4 -> H5 手离开、捧脸（0.9 秒）-> H6 低头害羞（1.3 秒）-> 待机。手在 H1-H4 基本不动，只有她扭头；手腕在格子顶边 18px 内淡出。
- idle_hop 小跳（1190ms）：程序动作。
- idle_read 坐下看书（8360ms，列了两次，概率翻倍）。

### 看书 idle_read
待机 -> T2①② -> D①..D⑥（腿部重画的坐下 6 张）-> T④ -> S 看书段 -> 倒放起身，全部硬切，每帧 90-130ms，坐下约 1.0 秒。待机到 D② 脚完全不动（脚位置对齐到 idle 的脚），D③ 起头部沿平滑路径移到偏右的坐姿位置（画布宽度约 62%）。D⑥ -> T④ 硬切，T④ -> S① 用书/手局部贴图；翻页贴手和书；眨眼贴眼睛；抬头笑是把 S 第 3 格整个头硬切换入、硬切换出，不渐变。

### 点击与右键菜单
- 点击左/右键：随机播一个闲置小动作（reactions.clickLeft/clickRight 的 `files`+`durations`，需打补丁的 clawd；`file` 保留为 idle_hop 作退路）。双击（连点 4 下）：attention。
- 右键"做动作"菜单：theme.json 顶层 `actionMenu`（需打补丁的 clawd）：看书、工作（idle_work 7160ms：待机 -> W3 -> W4 -> W5 -> 打字约 5 秒带眨眼 -> W6 抬头笑 1.2 秒 -> W5 -> W4 -> W3 -> 待机）、思考（idle_think 4020ms：待机 -> W1 -> W2 -> 思考姿势约 3 秒 -> 回待机）、歪头、摸头、张望、小跳、伸懒腰、欢呼、打招呼、打哈欠。idle_work / idle_think 不在随机池和点击随机里，所以 validate-theme 会提示"2 个未引用文件"（警告，不影响使用）。

## 安装
把 `clawd-themes\honami-theme` 整个文件夹复制到 `%APPDATA%\clawd-on-desk\themes\`，在 Clawd 设置里选"一之濑帆波 (Honami)"。（脚本不会自动安装。）

## 已知问题
- 没有加 `transitions`（out 淡出）：离开 thinking/working 时旧图淡出会和新图叠加，正好叠出脸部重影，违背"脸不做淡化"。离开改为硬切，为减小跳变，所有站姿状态图的头部左右位置已对齐到 idle 的头。
- 不同状态用的是不同的格子（姿势不同），切入/切出必然有一次硬切：notification 与 idle 首帧差约 30，attention 约 23，sleeping 约 35（姿势不同，不是对不齐）。已去掉上一版加在它们首尾的淡化帧。
- 站->坐、坐->站的几步中间姿势只有素材里的 6 张，帧间位移较大（最大帧间差约 31-35，都是姿势变化），属于硬切的代价。Z2（站姿抱枕头）->Z3（坐下）之间只有一帧"屈膝"程序压缩帧。
- 动作菜单、点击随机依赖打过补丁的 clawd，官方版会忽略这些字段。
- working 保持段为控制文件大小用 420ms 一帧（呼吸每步约 2px），约 45 秒后循环回待机再重新进场；单文件最大 3.7MB（working）。
- 眨眼只有全开/全闭；提醒的感叹号、睡觉的 z、思考的问号随身体一起动。
- hitBoxes（取各动画范围并集）和 visibleHeightRatio(0.78) 为估值，装上后可能要微调。
